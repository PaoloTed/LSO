3. Esegue tutte le azioni il cui pattern risulta “vero”

Funzioni utili in awk
substr(stringa, inizio, [lunghezza])
Estrae una sottostringa da un campo o variabile.
Inizio: posizione da cui partire (1 = primo carattere).
lunghezza (opzionale): quanti caratteri estrarre.
Se lunghezza è omesso → prende fino alla fine della stringa.
Esempi:
substr("ciao",1,1) → c
substr("ciao",2,2) → ia
substr("ciao",3) → ao

Funzioni utili in awk
next
•
Termina l’elaborazione della riga corrente.
•
Passa subito alla riga successiva del file di input.
Utile quando:
•
Vuoi saltare righe particolari (es. intestazioni).
•
Usi la prima riga solo per inizializzare variabili.
•
In breve:“ho finito con questa riga, passa oltre”.
awk '/^$/ { next } $1 ~ /^a/ { print $2 }' file.txt
awk '/^#/ { next } $1 ~ /^a/ { print $2 }' file.txt

Comandi Esterni in awk
In awk si può lanciare un comando esterno usando una pipe:
comando | getline variabile
• Il risultato del comando viene letto e salvato in variabile.
• Dopo aver usato il comando, è buona pratica chiudere la pipe:
close(comando)
•
Esempio
BEGIN {
cmd = "date +%Y"
cmd | getline anno
close(cmd)
print "Anno corrente:", anno
}

Comandi Esterni in awk
Esempio:
Scrivere una funzione awk che restituisca il numero di file contenuti in una directory, 
usando comandi esterni.
ls -d */ | awk ‘
function conta_file(dir) {
cmd = "ls -1 " dir " | wc -l"
cmd | getline n
close(cmd)
return n
}
{
print $0, "contiene", conta_file($0), "file"
}'
