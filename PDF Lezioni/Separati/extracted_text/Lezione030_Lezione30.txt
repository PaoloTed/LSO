
Comandi di rete Docker essenziali
•
docker network ls #lista i network esistenti
• Bridge di default, host, none
•
docker network create miarete
• Crea una rete bridge virtuale
• ai container collegati assegna IP privati (tipo 172.18.x.x)
• i container su miarete si vedono tra loro come se fossero host diversi sulla 
stessa LAN
•
Collegare un container a una rete
• docker run --network miarete --name server ...
• docker run --network miarete --name client ...
–
--network miarete → mette il container nel net namespace collegato a quella rete
–
--name server → il nome diventa hostname e DNS interno sulla rete Docker (quindi client 
può contattare server per nome)
•
Ispezionare una rete
• docker network inspect miarete


Dockerfile
•
Un Dockerfile è un documento di testo che contiene tutti i comandi che un 
utente potrebbe eseguire da riga di comando per assemblare un’immagine
•
Contiene una sequenza di istruzioni eseguite in ordine
•
Permette di automatizzare e standardizzare la creazione dell’ambiente
•
Supporto la portabilità tra sistemi

Istruzioni principali
•
FROM – immagine di base
•
COPY / ADD – copia dei file
•
RUN – esecuzione di comandi durante la build
•
EXPOSE – porte esposte
•
CMD / ENTRYPOINT – comando di avvio del container

Docker

Esempio precedente …
•
server-bin.c e client-bin.c

Dockerfile server:
FROM ubuntu:22.04
# Compilatore per costruire il binario
RUN apt update && apt install -y gcc
WORKDIR /app
# Copio il sorgente C nell'immagine
COPY server-bin.c .
# Compilo dentro l'immagine
RUN gcc server-bin.c -o server-bin
# Quando il container parte, esegue direttamente il server
CMD ["./server-bin"]

# Default: si connette a "server-cont"
CMD ["./client-bin", "server-cont"]
