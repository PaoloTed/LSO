Select
select() permette di:
•
Attendere evento I/O su più socket contemporaneamente senza 
bloccarne uno mentre gli altri hanno dati pronti
•
Permette di evitare un thread per socket
•
Utile per gestire molti client in modo single-threaded

---PAGE BREAK---
Select
int select (int numfds, fd_set *readfds, fd_set *writefds, fd_set *exceptfds, 
struct timeval *timeout);
Header file sys/time.h, sys/types.h, unistd.h
• Controlla contemporaneamente lo stato di uno o più descrittori specificati
• Si blocca finché:
– non avviene un’attività (lettura/scrittura) su un descrittore degli insiemi
– non viene generata un’eccezione
– non scade un timeout
• Restituisce
– -1 in caso di errore
– 0 se il timeout è scaduto
– Altrimenti, il numero totale di descrittori

---PAGE BREAK---
Parametri Select
Insiemi di descrittori da controllare
– readfds: pronti per operazioni di lettura
Es: socket pronto per la lettura se c’è una connessione in attesa di accept()
– writefds: pronti per operazioni di scrittura
– exceptfds: exceptional conditions, quasi sempre nullo
readfds, writefds e exceptfds sono puntatori a variabili di tipo fd_set
– fd_set insieme dei descrittori (è una bit mask implementata con un array di interi)
numfds è il numero/range massimo di descrittori controllati da select()
– ATTENZIONE: Se maxd è il massimo descrittore usato, numfds = maxd + 1
– Può essere posto uguale alla costante FD_SETSIZE

---PAGE BREAK---
Timeout

timeout specifica il valore massimo che la funzione select() attende per 
individuare un descrittore pronto

Se impostato a NULL (timeout == NULL)
– select si blocca indefinitamente fino a quando è pronto un descrittore

Se impostato a zero (timeout->tv_sec == 0 && timeout->tv_usec == 0 })
– select non attende (da usare per polling dei descrittori senza bloccare)

Se diverso da zero (timeout->tv_sec != 0 || timeout->tv_usec != 0 }),
– select attende il tempo specificato
– select() ritorna, se è pronto, uno (o più) dei descrittori specificati 
(numero positivo) oppure 0 se è scaduto il timeout

---PAGE BREAK---
Impostazione degli insiemi

Macro utilizzate per gestire gli insiemi di descrittori
int FD_ISSET(int fd, fd_set *set);
– Al ritorno di select(), controlla se fd appartiene all’insieme di descrittori set, 
verificando se il bit relativo a fd è pari a 1 (restituisce 0 in caso negativo, un 
valore diverso da 0 in caso affermativo)

Select
La funzione select() rileva i descrittori pronti (non bloccati)

Significato diverso per i tre tipi di descrittori (lettura, scrittura, exceptional 
conditions)

Un descrittore è pronto in lettura se:
•
Nel buffer di ricezione del socket sono arrivati byte in quantità sufficiente (soglia minima 
per default pari a 1, modificabile con opzione del socket SO_RCVLOWAT)
•
Il peer ha chiuso il suo lato di scrittura (ricevuto FIN, leggerà fino ad EOF)
•
Si è verificato un errore sul socket
•
Se è un socket di ascolto (LISTEN) e ci sono delle connessione pendenti

Un descrittore è pronto in scrittura se:
•
Nel buffer di invio del socket c’è spazio sufficiente per inviare (soglia minima per 
default pari a 2048 byte, modificabile con opzione del socket SO_SNDLOWAT) ed il 
socket è già connesso (TCP) oppure non necessita di connessione (UDP)
•
La connessione TCP è stabilita (per UDP sempre ok)
•
Il peer ha chiuso il suo lato di lettura
•
C’è errore pendente sul socket


Significato diverso per i tre tipi di descrittori (lettura, scrittura, eccezione)

Exceptional conditions:
•
In Linux, l’unica condizione per cui select() segnala fd in exceptfds è 
OOB TCP data
•
Out-of-band data (OOB) per TCP → SIGURG / MSG_OOB
•
Dati urgenti segnalati così
•
Di leggono con:
recv(fd, buf, len, MSG_OOB);
if (FD_ISSET(c, &efds)) {
char buf[1];
printf(">>> OOB READY!\n");
int r = recv(c, buf, sizeof(buf), 
MSG_OOB);
if (r > 0) {
printf("OOB DATA: %c\n", buf[0]);
} else { perror("recv OOB");}
}

Esempio
#include <stdio.h>
#include <unistd.h>
#include <errno.h>
#include <sys/types.h>
#include <sys/select.h>
#include <sys/time.h>
int main(void) {
fd_set readfds;
struct timeval tv;
int nfds = STDIN_FILENO + 1;
FD_ZERO(&readfds);
FD_SET(STDIN_FILENO, &readfds);
tv.tv_sec  = 2;
tv.tv_usec = 500000;   // 2.5 s (usec: milionesimi di sec)
int n = select(nfds, &readfds, NULL, NULL, &tv);
if (n < 0) {
if (errno == EINTR) { /* ripetere se necessario */ }
perror("select"); return 1;
} else if (n == 0) { printf("Timed out.\n");
} else if (FD_ISSET(STDIN_FILENO, &readfds)) {
printf("Input disponibile (tipicamente dopo Invio).\n");
char buf[128]; // Esempio: leggere qualcosa
ssize_t r = read(STDIN_FILENO, buf, sizeof buf);
if (r > 0) write(STDOUT_FILENO, buf, (size_t)r);
}
return 0;
}














